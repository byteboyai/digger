# S3b-1 待办面板真机验收清单

日期：2026-10-25
分支：`feat/todo-panel`
环境：沙箱 Digger（独立 `DIGGER_DATA_DIR` + 临时 `HOME`），不要使用日常 `/Applications/Digger.app` 或用户常驻的 `diggerd`。

> 本清单由用户勾选。计划明确要求“真机清单的执行由用户做”，开发侧只交付清单。

## 准备

- [ ] 用独立数据根与临时 HOME 启动沙箱 Digger（例如 `DIGGER_DATA_DIR=/private/tmp/todo-accept/data HOME=/private/tmp/todo-accept/home <digger 可执行文件>`）。
- [ ] 确认启动的是本分支构建产物，且 `diggerd` 使用同一个临时数据根。

## 清单

1. [ ] 面板出现在左区图标栏，图标与悬停标题“待办”正确；点开是“左分类树 | 右任务列表”。
2. [ ] 新增任务（中文、emoji、很长一行、含换行各一条）：列表立即出现；重启 Digger 后仍在。
3. [ ] 勾选 / 取消勾选、改文字、拖动排序、定计划日期、改状态（待办 / 搁置 / 完成）：每项刷新后保持。
4. [ ] 分类：新建根分类与子分类、重命名、拖动换父级、上移下移、删除；任务挂到分类与移出。
5. [ ] 指派 agent：任务卡上选 Claude / Codex，刷新后徽标保持；**不会执行任务**（只写归属字段）。
6. [ ] 切项目：两个项目各有各的任务，来回切不串。
7. [ ] 收起 / 展开列表栏、拖窄窗口：webview 不盖住底部新增输入和左侧清空栏；收起整个面板后没有残留 webview。
8. [ ] 停掉 `diggerd` 再起：面板不报错、列表不清空；恢复后数据更新。
8b. [ ] 面板开着时，在另一个终端对同一个 `diggerd` 加一条任务（`Client::add_todo` 或集成测试用过的小工具），约 1 秒内出现在列表；面板收起后不再轮询（`diggerd` 日志里没有周期性 `ListTodos`）。
9. [ ] 在另一个窗口 / 用直接对库的手段删掉一条任务后，在页面上点那条：无反应、不崩。
10. [ ] 已知缺位（预期如此，不算 bug）：点卡片“打开详情”无反应（stderr 一行 `todo detail not available in Digger yet`）；文本框没有右键菜单；写失败没有可见提示，只落 stderr 并刷新回原样。
11. [ ] 与 Dozer 并排对照同一份数据的外观（分类树、卡片、日历、颜色），截图差异逐条记录。

## 备注

- 指派 agent 只写库字段，不触发 `task_poller` / `summaries`（S3b-1 非目标）。
- MCP 待办工具（S3b-2）不在本期，验收时不要从 MCP 侧调用待办工具。
