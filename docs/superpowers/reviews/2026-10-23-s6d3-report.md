## 实现要点

- **悬停(Task 1):** `AgentPanel` 记 `(AgentHover, Instant)`;进入记录、离开只清当前槽位;`hover_progress` 是阶跃(0/1),`hover_tooltip_ready` 满 2 秒,`tooltip_deadline` 供 1 秒 `Tick` 判断。库的 `Message::Hover` 由产品在 `update` 里拦截记账(库该分支是空的)。页签/关闭按钮/`＋`/溢出按钮都上报 hover;页签数量变化后越界的悬停自动清理。
- **页签(Task 2):** 新增 `adapters/agent_tabs.rs`,度量逐项对照 Dozer `chrome/tab_widget.rs`:内边距 10/4/0、选中 `card` 底 + 1px `border` + 圆角 6、悬停 `tab_hover` 底、标题 `font::body()`/`wrapping None`/`clip`、关闭按钮 `tab_button_size()`、静止透明、悬停 `dim`→`gold`;延迟提示 `Tooltip` 位置 Top、间距 4、气泡 `size 12` cream、内边距 `[5,9]`。
- **溢出(Task 2):** 按钮 `ChevronsDown`、命中区 `tab_arrow_button_size()`,页签组非空时总显示;菜单宽度 `clamp(win.w − anchor.x − 24·s, 220·s, 560·s)`、最大高 `320·s`、钳进窗口;行内固定 `>` 列(仅选中行有箭头)、行内边距 4、行距 2、行关闭常显;外框复用 `menu_overlay::shell`。页签条可用宽度 = 块宽 − 72·s,不小于 0。
- **覆盖层互斥:** 选择器与溢出下拉同一个时刻只有一个(Esc 按「确认框 → 选择器 → 溢出」关最上层);切换面板 / 项目 / 关项目都会关闭;打开时终端不收键盘。
- **拖拽(Task 3):** 按下页签(`SelectTab`)武装,卡片(`SelectTabNoDrag`)不武装;越过 `tab_drag_past_threshold` 才调库的 `reorder_term_tab(state, from, to)`,续拖以新位置为准;松开、光标离开窗口、失焦、切项目、关会话都清理;换位后清悬停。
- **画廊(Task 4):** 为了 example 能复用产品适配层,把 `crates/desktop` 拆出一个 lib 目标(`src/lib.rs`),`main.rs` 只留 boot/update/view。`examples/agent_gallery.rs` 接受 `--state <name>`,覆盖 `empty / one-shell / grouped / active-card / many-tabs / narrow / overflow-open / picker-open / confirm-open / notice / daemon-unavailable`,不连 `diggerd`。
- **文档:** `docs/superpowers/notes/2026-10-18-agent-parity.md`(状态摆法 + 差异清单骨架 + 技术债),`docs/adr/ADR-015-product-owned-daemon.md` 增「Agent 面板」一节。

## 已知且接受的差异

1. 悬停是阶跃(进入即满、离开即空),Dozer 是渐变(设计 D3)。
2. 延迟提示精度 1 秒(Dozer 逐帧)。
3. 覆盖层状态用 `picker` + `overflow` 两个互斥字段表达,而不是计划里的单个 `Overlay` 枚举——行为一致,少改 S6d-2 既有调用点;已在代码注释里写明互斥约束。
