## 实现要点

- **服务与 hook:** `Daemon::sessions()` 把同一个 `dozer_client::Client` 作为 `Arc<dyn SessionService>` 注入;`adapters/agent_hooks.rs` 的 `DiggerHooks` spawn 同目录 `digger-hook install <agent>`(Claude/Codebuddy/Codex/Qodercn/Opencode/Goose),Aider/V8agent/Unknown 不调用;不继承 stdin、丢弃输出、上限 10 秒(超时 kill 并收尸);`ensure_mcp` 空操作(D5)。
- **每项目状态:** `AgentPanel` 持 `HashMap<i64, AgentPanelState>`;消息 `Msg::Agent(pid, ..)` 只投给对应项目,项目页签已关则丢弃。守护进程不可用时什么都不启动;`Ensured(Ok)` 到达时若面板已可见会补一次懒启动(启动序列早于可见性的情况)。
- **恢复:** 面板首次可见 → `restore::fetch_restored` 在后台跑 → `Msg::AgentRestored` 带 `Arc<Mutex<Option<Vec<RestoredSession>>>>` 回 UI 线程;项目已关则整批丢弃并让 attach 接收端随 drop 关闭;没有会话时按**当时的网格**新开一个 shell(根在项目路径)。同一项目恢复在途/已有状态时不会二次启动。
- **关闭与退出:** 关项目页签清理状态、abort 转发、kill 该项目所有存活 `Daemon` 会话;删除项目(确认/注册表移除)也走同一条 kill 路径。关窗口只 abort 转发、不 kill;退出前并行等在途 kill,整体 3 秒上限,超时放弃。
- **展示:** `adapters/agent_display.rs` 实现库的 `PanelDisplay`:无悬停动画、列表在配对第一块、终端块第二块;页签是朴素版(状态点 + 标题 + 关闭 ×,选中实底),**溢出按钮返回 `None`、溢出菜单为空、拖拽原样透传**(Dozer 同款留给 S6d-3)。选择器浮层复用 `menu_overlay` 的同一套外框/行样式,条目与图标色取 `picker::picker_entries()`;点空白或 Esc 关闭且不创建。关页签确认框在 `pending_close_tab` 时覆盖显示。
- **网格:** `adapters/agent_layout.rs` 用 `Rect` → 终端块 → 扣内边距(8)与页签条(24+4+1)→ `TermStyle::grid_size`;退化尺寸至少 1×1、上限 `u16::MAX`。`update_host` 每条消息后比较一次,同网格不发、0 尺寸不发;`ensure_started` 的新会话按同一份网格创建。
- **失败不静默:** 库 outbox 的提示解析后写进 Agent 面板顶部一行红字 + `×`,同时 `eprintln!`;Digger 一期没有 Toast。
