# 浏览器面板遗留与未决

日期:2026-10-28。计划:`dozer/docs/superpowers/plans/2026-10-28-digger-browser-panel.md`;设计取舍见 `docs/adr/ADR-016-browser-panel-untrusted-content.md`;探针结果见 `docs/superpowers/reviews/2026-10-28-browser-panel-spikes.md`。

## 发布前必须定 / 必须验

1. **最低支持的 macOS 版本没定。** 全部实测只在 macOS 26.6.2 上做过。宿主在交给 wry 前自己做百分号编码,本意是保护旧系统(wry 对 `NSURL::URLWithString` 直接 `unwrap`,旧系统遇到含空格 / 中文的原始网址可能返回 nil 而 panic),但没有在旧系统上跑过。要在发布前选一个下限并实测。
2. **真实窗口验收(验收清单 I 区)还没做。** 自动测试覆盖状态机、几何公式、生命周期、事件映射;webview 层级、焦点时机、输入法、Edit 菜单对 iced 输入框快捷键的影响、页签栏 + 地址栏实际高度是否等于 `chrome_top_px()`(网页有没有压到或露出缝)只能人眼看。
3. **未测的权限:** 定位(`navigator.geolocation`)。wry 没有钩子,依赖系统授权,可能弹系统提示,探针没有冒险去触发。

## 已知局限(v1 有意不做)

- 页内查找(⌘F)、下载、开发者工具、多窗口、私有模式。
- 页签拖拽换位;收藏夹侧栏分隔条拖拽(固定 28%)。Digger 的壳没有对应通路。
- 保留每个项目的页面:换项目就销毁重建,切回来按各页签保存的网址重新加载(滚动位置、表单内容丢失)。
- 页面里点击指向被拒 scheme(`mailto:`、`tel:` 等)的链接时静默无反应,没有提示。
- 导航失败没有明确原因:wry 没有"导航失败"回调,只有 15 秒内没开始加载的"没有响应"提示。
- 页签悬停动画:Digger 之前的约定是无悬停动画(D2),这里按库接口透传并由 16ms 探针推进,是否保留看验收时的观感。

## 与 Dozer 共用库带来的行为变化

- 地址栏输入以 `/` 或 `~/` 开头的裸路径,现在转成 `file://` 打开,而不是报"浏览器不支持打开本地文件"(2026-10-28 用户裁决,Dozer 同步变化)。`//host/…` 与没有 `$HOME` 的 `~/` 仍报该错误。

## `file://` 的风险(用户应知道)

本地页面不拿到任何宿主权限,但它仍是网页:能加载远程资源、发网络请求,没有 CSP。实测它用 `fetch` 读不了同目录之外的本地文件;`XMLHttpRequest`、`<iframe>`、`<form>` 等路径没有逐一测。

## 画廊的局限

`cargo run -p digger-desktop --example browser_gallery -- --state <名>` 只画视图,网页区是空白占位;内联错误(`inline-error`)的内容读不到契约,只能在窗口里看。
